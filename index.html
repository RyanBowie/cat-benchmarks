How they were built

GitHub Copilot app

Six cats. Each model ran in its own fresh GitHub Copilot session at its highest available reasoning effort.

Prompt→Plan→Write code→Build / bundle

Copilot sessions can run the shell, so several models set up a project and bundled it into one HTML file.

Microsoft Cowork

One cat. Claude Opus 5.5 was tested in Microsoft Cowork rather than GitHub Copilot, and delivered a single self-contained HTML file.

Prompt→Single HTML file→Done

Different harness, different tools, so treat the credit comparison as indicative only.

Ground rules

  • Identical prompt every time.
  • Highest reasoning setting for every model.
  • No hand edits: each page is published exactly as the model produced it.
  • Credits as reported by the tool for that session. MAI-Code-2-Flash was not reported.
🐾 Just a bit of fun, not a rigorous benchmark. One run per model, so luck matters. Source on GitHub · Cats run three.js, some load it from jsDelivr.
